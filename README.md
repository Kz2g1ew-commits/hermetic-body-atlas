# Corpus Hermeticum — 전자기 인체 아틀라스

프란츠 바르돈의 『헤르메스학 입문』 이론부에 수록된 ‘인체의 오컬트 해부학’을 탐색하는 인터랙티브 3D 웹사이트입니다. 전기 유체의 팽창은 빨강, 자기 유체의 수축은 파랑, 중성 구획은 금색, 가슴 앞의 전자기 혼합은 교차하는 빨강·파랑으로 표시합니다.

## 실행

```bash
npm install
npm run dev
```

터미널에 표시되는 로컬 주소(기본값 `http://localhost:5173`)를 브라우저에서 여세요.

프로덕션 빌드는 다음 명령으로 생성합니다.

```bash
npm run build
npm run preview
```

## 조작

- 인체 드래그: 시점 회전
- 마우스 휠 또는 트랙패드: 확대·축소
- 왼쪽 신체 부위 또는 3D 인체 클릭: 해당 부위로 이동 및 확대
- 눈·귀·입과 혀 선택: 해당 해부 메시 중심으로 이동해 극성 표식을 확대
- 전기장/자기장/균형장 버튼: 각 장을 독립적으로 표시·숨김
- 선택 부위만: 다른 부위의 오라를 숨기고 현재 부위의 극성 위치 핀만 표시
- 전신 함께: 전체적인 극성 장식을 함께 표시
- 인체 비례: MakeHuman 원본과 화면용 남성형 비례 보정을 전환
- 우세손 적용: 전신 좌우 방사만 반전하거나, 우세손·손가락 대표 극까지 반영하거나, 왼손잡이일 때 모든 부위표의 전기·자기를 반전하는 비교 보기
- 균형 해석: 원문의 전자기 혼합·중성 구분과 보라색 통합 해석을 전환
- 부위 연결: 연결 없음, 가까운 실제 노드끼리의 근거리 연결, 주요 부위까지 잇는 전신 연결을 전환
- 전체: 전신 보기로 복귀
- 회전: 자동 회전 켜기·끄기

> 이 프로젝트는 바르돈의 헤르메스학적 인체관을 시각화한 교육·예술용 모형이며, 의학적 진단이나 물리학적 생체장 측정 모델이 아닙니다.

부위별 설명은 프란츠 바르돈의 *Initiation into Hermetics* 중 “The Occult Anatomy of the Body”와 같은 책의 전기·자기 유체 설명만을 기준으로 합니다. 머리부터 마지막 척추와 항문까지 원문 표의 14개 항목을 모두 반영했습니다. 자세한 원문 대응과 화면 표현 원칙은 [METHODOLOGY.md](./METHODOLOGY.md)를 참고하세요.

## 3D 모델 출처

인체 표면·안구·혀는 AI 생성물이 아니라 MakeHuman 공식 기본 메시를 사용합니다. 피부 약 8만 렌더 정점과 같은 원본 좌표계에 들어 있는 안구 및 혀 보조 메시를 함께 불러오며, 귀 강조면은 피부 메시의 실제 귓바퀴 삼각형에서 추출합니다. 기본 메시는 CC0로 공개되어 있습니다. 기본 ‘남성형 보정’은 메시를 대체하거나 AI로 재생성하지 않고 어깨·흉곽·골반의 화면상 비례를 완만하게 바꾸며, 원본 보기로 되돌릴 수 있습니다. 세부 출처와 파일 검증값은 [ASSETS.md](./ASSETS.md)를 참고하세요.
